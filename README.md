# Scanner Híbrido

Página web de diagnóstico para Toyota RAV4 Hybrid com adaptador OBDLink CX (Bluetooth LE).
No iPhone, abrir no app **Bluefy** (o Safari não tem Web Bluetooth). Funciona também no Chrome do Android e do PC.

Somente leitura, exceto apagar códigos de erro (com confirmação). Nunca grava, reseta módulos ou desbloqueia segurança.

Comandos da bateria de alta tensão e endereços dos módulos: base aberta
